# Веб-уроки EasyCode

`index.ts` содержит двенадцать уроков по темам исходного плана: четыре шага чтения, три вопроса мини-проверки и практическое задание в каждом. Названия и порядок совпадают с `content/materials/catalog.json`.

## Происхождение текста

| Уроки                             | Основа                                                                                                                              |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 1.1, 1.2                          | Адаптация предоставленных презентаций и конспектов учителя; добавлены примеры текущего симулятора                                   |
| 2.1, 2.2                          | Адаптация предоставленных презентаций про блочную среду; возможности Scratch отдельно отличены от EasyCode                          |
| 3.1                               | Адаптация предоставленного конспекта о циклах; текст для ученика и примеры учебного языка написаны для платформы                    |
| 3.2, 4.1, 4.2, 5.1, 5.2, 6.1, 6.2 | Новые авторские тексты по названиям тем из плана курса; отдельных исходных презентаций или конспектов для этих тем не предоставлено |

Это не автоматическая дословная конвертация файлов и не новые презентации. Оригиналы остаются в `content/materials/`. Поле `source` каждого урока показывает его происхождение. Перед использованием с классом автору курса следует проверить формулировки, возрастную сложность и педагогические критерии.

## Границы практики

Исполняемые примеры используют ограниченный язык машины: движение, повороты, фиксированные циклы и `if robot.obstacle_ahead()` с необязательной веткой `else`. Поворот не перемещает машину. Размеры движения Scratch в пикселях, зелёный флаг, речь и звук не выдаются за возможности EasyCode.

Практика 5.1 и 5.2 — только смысловые модели на бумаге или карточках: без соединения реальных компонентов и без заявления о существующем электронном редакторе. У этих уроков `availableInSimulator: false`. Остальные задания рассчитаны на подготовленное поле машины; свободный конструктор карт не предполагается.

Успешная мини-проверка подтверждает ответы по уроку, но не заменяет отдельный запуск практической программы. Эти задания не означают, что уже подготовлены все 18 упражнений полного курса.

## Ответы и проверки

`LessonDefinition` содержит ключи и объяснения к мини-проверкам. Этот модуль импортируется только сервером; клиент получает публичный тип `Lesson` без ключей ответов. Не импортируйте определения уроков в `src/` ради удобства отображения.

Проверены соответствие каталогу, уникальность идентификаторов, четыре шага и три вопроса на урок, правильность ключей и разбор всех двенадцати примеров общим движком. Пример в уроке 6.2 намеренно сталкивается с препятствием: это материал для поиска ошибки, а не готовое решение.
